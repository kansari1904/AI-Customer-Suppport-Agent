09 — Data Sync Issues
My FlowDesk data is not syncing correctly

If data from an integration is not appearing in FlowDesk, open Settings → Integrations and check the connection status.

Try disconnecting and reconnecting the affected integration. Some integrations may take several minutes to synchronize new information.

If the sync remains stuck for more than 30 minutes, contact support with the integration name and the approximate time when the problem started.
