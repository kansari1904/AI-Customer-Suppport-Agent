# 🤖 AI Customer Support Agent

An AI-powered customer support application that uses **LLMs and Retrieval-Augmented Generation (RAG)** to provide accurate, context-aware responses to customer queries based on a predefined knowledge base.

## 🚀 Features

- 🤖 AI-powered customer support
- 📚 Answers questions using a knowledge base
- 🔍 Retrieval-Augmented Generation (RAG)
- 🧠 LLM-powered responses
- ⚡ FastAPI backend
- 🌐 REST API
- 💬 Context-aware responses
- 🔐 Environment variable support for API keys
- 📖 Automatic API documentation with Swagger
